# Ten PPO screening trials

Requested on 2026-09-05. Ten sequential runs, each 300 updates with 1,024
environments and seed 42. All start from the same flat `model_1300.pt` (2026-07-02
run). Total comparison budget is 3,000 updates across ten independent models;
no continuation to 5,000 is started automatically by this batch.

Reward functions and weights are unchanged. Stair terrain retains the existing
5–15 cm height / 50–30 cm tread curriculum. All trials share forward/backward
commands [-0.8, 0.8] m/s and yaw commands [-0.6, 0.6] rad/s. Lateral velocity is
zero. This command mix also differs from the earlier forward-only runs, so compare
these ten trials with each other rather than treating old rewards as equivalent.

The baseline uses adaptive learning rate 0.001, entropy coefficient 0.008431,
clip 0.2, desired KL 0.01, gamma 0.99, lambda 0.95, and five PPO epochs.
Variants change fixed learning rate (0.0003 or 0.0001), entropy (0.003 or 0.02),
clip (0.1), desired KL (0.005), gamma (0.995), lambda (0.98), or epochs (3).
Actual commands and overrides are preserved in `manifest.json` and the trial JSONs.

## Tracking

From the repository root:

```bash
python scripts/co_rl/stair_oracle/batch_status.py
tail -n 65 scripts/co_rl/stair_oracle/batches/ten_20260905_a/01_baseline.log
systemctl --user status stair-train-ten-20260905-a.service
```

`status.json` updates every five seconds. Each trial retains stdout, checkpoints,
TensorBoard events and oracle attempt CSVs. `ranking.json` is created when the
queue finishes or stops normally, ranked by the last 50 training terrain-level
and reward samples. It is a preliminary screening ranking, not a held-out
benchmark. Oracle-labelled training attempts are not human BC demonstrations.
No videos or human waypoint demonstrations are generated by this batch.

## Runtime limits

One simulator at a time, shared exclusive lock with waypoint replay, RAM high
watermark 6 GiB / maximum 7 GiB, swap maximum 256 MiB, whole batch limit three
hours. Each trial has a 20-minute wall limit and a four-minute no-update limit.
A failed trial stops the queue for inspection. Completed workers flush their
files and exit directly to avoid native Kit teardown hangs. Existing output
directories with status files cannot be relaunched accidentally.

To stop this batch and its worker:

```bash
systemctl --user stop stair-train-ten-20260905-a.service
```
